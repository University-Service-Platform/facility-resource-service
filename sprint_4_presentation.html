1. Production Architecture (Database-per-Service)

Strict bounded contexts with isolated MySQL 8.0 instances, token-forwarding REST communication, and OAuth2 resource server security.

• facility-resource-service (Port 8081): Master data for venues, labs, operating hours, capacity bounds, and cross-team validation endpoints.

• university-reservation-service (Port 8082): Dynamic booking workflow, auto-approval heuristics, manager review audit log, and external token forwarding.

• Security & Gateway: Group 5 Identity Service (RS256 JWKS) + Group 5 API Gateway routing.
